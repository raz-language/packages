# yaml

A bounded block-style YAML 1.2 core for Raz.

Version 0.1.0 provides borrowed iteration over document markers, mappings, sequences, inline sequence mappings, comments, quoted and plain scalars, core scalar classification, checked integer parsing, scalar unquoting, and caller-owned emission. Anchors, aliases, tags, flow collections, block scalars, and unsupported escapes return explicit errors rather than being guessed or silently accepted.
